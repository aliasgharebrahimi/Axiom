# Z_Score

> In other words, it refers to how many standard deviations away a specific number is within a set.

**Formula:**

$$z = \frac{x-\mu}{\sigma}$$

**Example:**

Let us assume the value in question is $80$, the mean of the set is $60$, and the standard deviation is $10$.

* **Paste into the formula:**

$$z = \frac{80 - 60}{10}$$

* **Deriving the formula:**

$$z = \frac{20}{10}$$

* **Get the value of z:**

$$z = 2$$

**So Z_score:** $2$
